# 明日之星活动方案与主持手册

## 一、活动要解决什么问题

很多团队成员知道彼此“很可靠”“很辛苦”，却很少在具体工作发生时认真表达。明日之星把欣赏变成一种低压力的集体练习：先让每个人独立书写，再通过游戏共同发现团队中被反复提及的品质，最后以游戏成绩完成轻松的现场仪式。

活动的核心不是选出“最值得欣赏的人”，也不是比较谁收到的卡更多。欣赏卡用于表达与回忆，排名只反映现场游戏成绩。主持时应始终区分这两件事。

## 二、推荐组织方式

- **人数：**6—40人较容易组织；更大规模应先做压力与现场流程验证。
- **会前准备：**预留3—5天收集欣赏，给成员足够的回忆和书写时间。
- **现场人员：**1名组织者操作中控，1名主持人口播也可以由同一人兼任。
- **设备：**组织者电脑、独立大屏或投影、成员手机、稳定网络。
- **现场时长：**约60—90分钟，根据题量调整。

## 三、会前准备

1. 部署空库，配置本团队名单，分发独立初始密码。
2. 确认成员能登录，并提醒首次登录后修改密码。
3. 解释署名与匿名的含义：匿名卡对成员、大屏和普通报告隐藏作者，但授权的组织者可以审计。
4. 鼓励写具体事件，而不是只写“很好”“很辛苦”。
5. 检查隐私和数据处理要求，尤其是使用外部大模型之前。
6. 用虚构内容或独立演练环境熟悉中控，不要用真实活动成绩做试验。

可参考的邀请文案：

> 这次活动邀请你认真看见一位或多位同事。可以是一次及时补位、一段耐心解释，也可以是你对自己的认可。内容可署名或匿名，每张卡独立设置。欣赏没有标准答案，也不需要比较文采。

## 四、建议现场流程

### 1. 开场与书写回顾（5—10分钟）

组织者确认所有展示设备连接正确。主持人说明：活动关注真实协作，不按收卡数量评价任何人；游戏可以竞争，欣赏不需要竞争。

### 2. 截止与关键词准备（会前或现场开始前完成）

确认提交完成后，组织者在“筹备与截止”结束收集。固定快照后生成关键词建议，审核近义词并手动发布。

关键词用于“全民预言家”，不是对成员的人格评价。应避免把负面、讽刺或证据不足的内容做成标签。

### 3. 真心话抢答（20—30分钟）

组织者按被欣赏人选择题卡，注意覆盖不同同事，而不是连续使用同一个人的卡。匿名卡也可以参与，因为大家猜的是接收人。

每题的标准节奏：

> 展示正文 → 30秒作答 → 揭晓被欣赏人 → 简短邀请大家感受这段具体协作 → 下一题。

不要临时增加“猜作者”或“揭晓匿名推荐人”。如果一段内容过于私人或不适合公开，应在选题时跳过。

### 4. 全民预言家（10—15分钟）

成员从审核后的候选词中选3个。主持人可引导大家思考：哪些品质不是只出现一次，而是在多段真实协作中反复出现？

选择期间不展示词频。截止后揭晓真实Top 5，并借关键词回顾团队文化。第五名同频时，并列标签全部计入。

### 5. 欣赏连连看（10—15分钟）

每位成员处理自己收到的全部卡。署名卡连接真实作者，匿名卡只判断为匿名。组织者确认成员已经打开页面后再启动统一120秒计时。

如果成员没有收到卡，系统会显示空状态；主持人不要为其编造题目或分数。

### 6. 排名、颁奖与收尾（10—20分钟）

按照三个游戏的总分排名，前三个名次可以包含并列。得0分的实际参与者仍保留在完整名单中，未参加者不被虚构为参与者。

颁奖后可邀请成员分享“今天意外看见的一次贡献”。自我金句只能来自真实、署名的自我欣赏，不要公开匿名自我欣赏的作者。

## 五、试玩与正式活动

试玩用于确认设备和规则。试玩与正式成绩隔离，普通成员页和大屏不显示试玩提示。

只有组织者可以在筹备状态切换模式。清理试玩必须输入精确确认文字，只删除当前试玩轮次的游戏答案和得分，保留欣赏卡、成员、提交锁、快照与关键词版本。正式成绩没有清理入口。

## 六、现场异常处理

- **页面暂时没有更新：**先等待约两秒，再检查网络；不要连续推进阶段。
- **成员无法登录：**核对选区、姓名和密码，不要公开尝试他人密码。
- **模型生成失败：**保留快照，查看错误后重试；不要删除欣赏卡或重新开放收集。
- **连连看尚未准备好：**不要启动120秒计时。
- **误进入下一环节：**系统不提供随意跳回；保持现场秩序，按实际状态继续并记录问题。
- **数据需要导出：**由组织者导出并作为内部敏感资料保存。

## 七、活动原则

1. 真诚优先于文采，具体优先于套话。
2. 匿名是一种选择，不是一个等待被破解的谜题。
3. 游戏排名不等于成员价值，也不等于欣赏数量。
4. 空数据正常展示，不用虚构内容制造热闹。
5. 任何公开部署都要先保护账号、评语、密钥与备份。
