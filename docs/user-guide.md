# 普通成员与组织者使用指南

## 普通成员

### 登录与账号

打开网站，选择所在选区、本人姓名并输入初始密码。登录后可从右上角姓名菜单修改密码或退出。新密码为8—20位，至少包含英文字母和数字。

同一账号属于多个选区时，修改密码会作用于其所有选区。系统没有公共密码找回入口，请妥善保管。

### 写欣赏

至少选择1人，人数不限，也可以自荐。每张卡独立填写、独立设置匿名，默认署名。每张卡去除首尾空格后为1—1000个Unicode字符，不是所有卡合计1000字。

草稿会自动保存到服务端，也可手动保存；看到保存成功后再离开。空白内容不能正式提交。

收集开放期间，正式稿仍可修改正文和匿名设置，也可新增接收人。已提交接收人不能直接删除或更换。正式稿修改需要手动确认保存，不使用草稿自动保存。组织者截止后，所有内容最终锁定。

普通成员不会看到全组提交人数、卡数、百分比或收集进度。

### 真心话抢答

阅读谜面，选择这段欣赏**写给谁**，不是猜谁写的。每题30秒，每人一次作答机会。答对得100分，并根据服务端剩余时间获得最高20分速度奖励；答错或超时不得分。

组织者只揭晓被欣赏人，不揭晓推荐人。

### 全民预言家

从候选关键词中选择3个不同标签，预测哪些会进入真实频次Top 5。选择时不显示词频。在中控截止前可修改。

每命中1个得100分，三个全中额外奖励300分，即可能得到0、100、200或600分。第五名同频时，并列标签全部算命中。

### 欣赏连连看

题目是本人收到的全部正式欣赏卡，不是全场所有卡。左侧为欣赏内容，右侧为候选作者和“匿名”。可以点击配对或拖动连线。

署名卡连接真实作者；匿名卡只连接“匿名”，不能也不需要猜真实作者。每卡第1、2、3次连对分别得100、80、60分，第4次起不得分。本人全部卡一次连对额外加300分；0卡没有奖励。

全场统一120秒，刷新或切页不会延长计时。

### 排名与颁奖

总分为真心话、预言家和连连看之和。实际参与者包括0分成员；只打开页面不算参与。同分同名次，前三个名次含并列者。全0时正常显示空状态，不生成虚构获奖者。

## 组织者

### 活动前

使用本选区组织者账号进入中控，核对选区名称。查看正式提交和已提交真心话，确认人员名单与收集情况。草稿不计入正式卡。

组织者可以审计匿名卡真实作者，但不得把该信息展示到大屏或公共报告。

### 结束收集

在“筹备与截止”点击“结束欣赏收集并进入筹备”，按提示输入“结束收集”。此操作固定正式卡快照并锁定新增、提交和修改，不会自动开考，也不会删除草稿或提交锁。

### 关键词

固定快照后点击“生成关键词建议”。系统将全场正文一次性提交给配置的模型，全局归并四字标签。组织者审核整组词、修改名称或合并近义词，再点击“审核完成并发布”。

服务端按每张卡在每个标签下最多一次计算真实频次。未发布或候选不足5个时不开放预言；预言开始后不能原地替换绑定版本。

### 真心话中控

全部正式卡均可参与，包括匿名卡。可按被欣赏人、正文、卡号和题目状态筛选，也可随机选择未用卡。

依次执行“指定下一题／随机未用”→“展示谜面并开考”→“提前结束作答或等待30秒”→“揭晓被欣赏人”。已用卡置灰，环节结束后题库只读。

### 预言、连连看与成绩

确认关键词已发布后推进预言，按页面顺序截止和揭晓。连连看必须等成员就绪后再启动120秒统一计时。

“成绩与审计”展示三个分项、总分、完整参与者名单和颁奖结果。JSON／CSV导出可能包含私人评语与匿名作者，仅限授权管理使用。

### 试玩清理

只有在筹备状态可以切换试玩／正式成绩。清理试玩需输入“清除试玩”，只删除当前试玩轮次的预言、抢答、连线与得分，保留欣赏卡、作者关系、成员、提交锁、固定快照和关键词版本。它不会重开收集，也不能用于正式成绩。

## 独立大屏

从当前选区的页面或中控打开大屏，确保链接带有对应选区参数。大屏用于16:9投影，展示真实阶段与数据；会前收集不展示0人、0卡或0%等统计，普通成员页和大屏也不显示试玩提醒。
